# Complete combatant art coverage

Generated with the built-in image-generation tool, using the existing NPC artwork as identity references. Original idle/walking images and dialogue portraits are not replaced.

## Consumption and registration

`src/data/npcCombatArt.ts` selects by actual visual identity, including the regional citizen slot and the male hunter's weapon. Separate front/back correction sheets avoid sideways vertical attacks. The blacksmith's side animation selects complete consistently facing poses; no body-part stitching. Whole right-facing poses are reflected for left facing. All five regional officers use their dedicated contact/passing gait sheets in `../walking/`; the older combined walk rows and `darkav-gait.png` are retained sources, no longer consumed as walks. Darkav's attack body has a separate fixed calibration to match its gait. Frame timing maps the actual extension/release to exactly one strike.

Additional sheets load only when needed. The six-family lazy cache retains active/returning actors and releases unused sheets after guards finish returning; the original guard/roadwarden sheets remain boot-prepared. Regional frames pack into 6x6 rather than oversized strips; all prepared atlases stay below 2048px per side. All nearby eligible fighters can join, including newly streamed residents during an event. Each chooses its own opponent, favors less-contested foes, and reserves a spaced approach or local sidestep within the arena. No player-hit prerequisite, shared two-attacker queue or 20% lifetime cap remains. Each hit is still only 2.5% max HP before defense, with a personal 2.3-second cooldown. Helpers can finish event enemies through saved-wave defeat handling, without player-luck bonuses, target hijacking, stun-locks or extra rewards. Eight pooled arrows remain non-homing, wall-blocked and cleared on pause, cinematic, event exit or death.

Size follow-up: body/whole-silhouette references come from the unchanged idle art; an upright carried pike must not be counted as helmet-to-boots height. The elven combat model shares the idle/walk size multiplier, and the priestess walk includes the same staff-inclusive silhouette as idle. Entire poses retain one calibrated scale, never stretched independently for each frame. Release verification of this follow-up passed application/test TypeScript, the production web build, 89 scoped regression cases, two autonomous-defender cases and both desktop/touch WebGL reviews (21 atlases, 43 combatants, 172 directional attacks per profile run). Rendered sheets were inspected again. Physical Android and a full-world playthrough remain unverified locally; APK packaging is performed by the repository's release workflow.
