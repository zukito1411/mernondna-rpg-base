# Complete NPC walking poses

Generated using the built-in image-generation tool. Original walking and idle source files remain intact; the game uses new sibling walk assets. Seven base families have four-direction walking clips, with the complete right-facing poses mirrored for left. Five regional officer gaits load with their event-combat family, rather than being preloaded for the whole world. Human and elven guard walk sequences are retained; the elven source uses measured row boundaries to exclude neighboring boots without cropping its own.

Each new source has four columns and three rows (down/right/up): contact, passing, opposite contact, passing. Production preparation segments full actors, applies one body scale per source, registers boots, and packs transparent GPU gutters. No body-part stitching. Idles and portraits are unchanged. Replaced base walking atlases and temporary source textures are released after preparation.
