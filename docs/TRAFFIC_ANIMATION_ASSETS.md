# Traffic animation artwork

These project assets were generated with the built-in imagegen tool and the imagegen skill. Horse and cart parts use merchant-cart.png as their edit/style reference. Images retain real transparent alpha; transparent RGB values may still contain background color but do not render in-game.

Final files are in public/assets/vehicles. Horse sheets each contain four gait poses. cart-parts.png contains four wheel-less wagons and detached wheel art. water-foam.png contains four dissolving foam patches. VehicleArt.ts records the cart source measurements and prepares compact, uniformly scaled motion cells.

## horse-east

Use case: precise-object-edit. Input image is the edit target and style reference. Extract the SAME chestnut draft horse with pale mane, pale feathered hooves and dark leather pulling harness from the supplied cart. Preserve painterly medieval RPG style, warm dark outlines, shape and tack. Create an actual four-frame WALK cycle, a slow four-beat walking gait with alternating planted/lifted hooves, NOT galloping. Exactly FOUR complete horse-only sprites arranged in an equal 2x2 grid, read top-left, top-right, bottom-left, bottom-right. The same fixed elevated orthographic RPG camera, same direction in ALL frames. Same head, torso dimensions, consistent source scale, head center and grounded baseline across all frames. Only legs, tail and subtle torso motion differ. No cart, wheels, rider, ground, shadow, speed lines, labels or backgrounds. Real transparent alpha. Each complete horse stays fully inside its cell with at least 8 percent margin and a 15 percent transparent gutter between neighboring horses. Direction: horse facing RIGHT/east, a side view from the elevated game camera showing all four legs. Frame1 near fore hoof planted forward, frame2 near fore passing beneath torso, frame3 opposite fore hoof planted forward, frame4 opposite fore passing. Front and rear legs stagger in a believable walking sequence.

## cart-parts

Use case: precise-object-edit. Input image is edit target. Disassemble the supplied illustrated medieval chestnut-horse merchant-cart sheet into CART BODY and WHEEL assets. Preserve the exact oak cart, grain sacks, barrel and rolled green cloth style, perspective and colors. Remove EVERY horse and EVERY wheel from the four cart bodies, leave transparent holes where wheels were. Keep the axle/hub behind the missing wheels and the two long forward shafts intact. Strict 2 columns by 3 rows, SIX independent items separated by broad transparent gutters: top-left cart pointing DOWN with shafts forward toward bottom; top-right cart pointing LEFT with shafts toward left; middle-left cart pointing RIGHT with shafts toward right; middle-right cart pointing UP with shafts toward top; bottom-left ONE separate face-on perfectly round wooden spoked iron-rim wagon wheel, axle hub centered; bottom-right ONE second identical perfectly round spoked wheel with a slightly different warm wood pattern, hub centered. Wheels must be perfectly circular, NOT ellipses, because game rotates these wheels then applies perspective. Cargo bodies MUST have no wheels and no horses. Fixed elevated RPG camera for bodies. Real transparent background, no text, no labels, no floor, no shadows, no lines outside the authentic cart shafts. Same scale for all four cart bodies. Each item fully within its own grid cell with 10 percent margins.

## water-foam

Use case: stylized-concept. Asset: animated water foam sprite sheet for hand-painted medieval top-down RPG. Four-frame looping soft wave-foam animation, exact equal 2x2 grid, same elevated top-down view and scale in all frames. Each cell contains one broad shallow irregular crescent PATCH of sea foam with many soft painted turquoise-white bubbles, frothy clusters, speckles and translucent blue-green eddies. Foam grows, spreads, breaks into bubbles, then dissolves across the four frames. Natural painted textured foam, NOT drawn strokes, lines, symbols, ribbons, zigzags, sharp crescents or geometric shapes. Designed to be a subtle overlay on detailed blue painted ocean. Each patch fully inside its cell with 15 percent margins; genuine transparent background around and between patches, no solid sea square, no scenery, no objects, no shadows, no text, no labels. Matching detailed painterly sprite style with natural muted highlights.
