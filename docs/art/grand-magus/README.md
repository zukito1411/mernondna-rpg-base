# Grand Magus source artwork

Created with built-in image generation. Versioned masters here match runtime
PNGs in `public/assets/enemies/grand_magus`; armor is in
`public/assets/items/shadow-magus-armor-v1.png`. Existing Ashen Seer artwork was
a supporting RPG rendering-style reference, not a replacement target.

The approved down board was the identity reference for subsequent boards.
Transparent output was requested for every image. Six-pose boards use three
columns and two rows: neutral, glide, cast preparation, cast release, staff
windup, staff strike. Side faces right (left mirrors the complete pose).
Rear has no face/beard. Atlas registration uses one shared body scale across
all three boards, not individual action-silhouette fitting.

Prompt requirements: black hood with unseen face and only a grey beard;
black/violet layered robes with silver fittings; violet-crystal staff in a
consistent hand; complete single-body poses, transparent gutters, no clipped
staff/robe, no text, labels, scenery or UI. Preserve identity and proportions
from the down reference when authoring profile and rear views.

Dissolve prompt: same Magus in six successive full, contained poses, cracking
into violet shards then dark violet bats; last poses disperse with no corpse.
Bat prompt: one four-column flap cycle, small black/violet bat with consistent
proportions, generous transparency, no scenery or text.
Armor prompt: three distinct, complete item designs—blackened-silver Magus
cuirass, matching boots, hooded violet cloak with bat-wing clasp; no character,
weapon, background or text. Authored positions are measured alpha regions,
not equal-third crops, to preserve complete item silhouettes.
