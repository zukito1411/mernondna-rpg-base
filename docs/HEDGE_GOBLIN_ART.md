# Hedge goblin art — M14a

Created with the built-in image generation tool, using the existing Rindass raider as a style reference. No CLI/API fallback was used. Original generated files remain in the Codex generated-images folder; selected files are copied into the repository.

## Saved assets and playback

- `public/assets/enemies/hedge_goblin/walk.png`: 5 columns × 3 rows, down/right/up. Neutral frames are idle-only. Right-facing full poses are mirrored into the left-facing atlas cells.
- `public/assets/enemies/hedge_goblin/actions.png`: 6 columns × 3 rows, directional windup/impact/recovery/hurt/collapse/fallen poses.
- `public/assets/enemies/hedge_goblin/complete-poses.png`: two genuinely opposite down-facing contact poses plus a complete replacement fallen pose. The clipped back-facing death pose and repeated down-facing contacts from the original boards are not used.

`GoblinArt.ts` isolates entire connected subjects, calibrates fixed scale against neutral/recovery profiles, and registers standing frames using the hood/torso horizontal root and grounded silhouette. Source down-facing passing poses 1/3 are paired with the replacement contact poses. Side/back cycles use source poses 1–4. No upper-body/leg stitching or drawn-line limbs. Intended visible standing height: 64 world units, deliberately shorter than the adult human protagonist (76), not a mis-scaled human.

The prepared atlas has 44 frames in a 2048×1344 RGBA canvas (10.5 MiB raw, excluding driver overhead). Three source textures are released after preparation. Spawn placement uses bounded attempts and the existing 16-hostile cap; no new per-frame full-world scans. This is a source resource calculation, not a measured performance claim. Further family additions should review regional asset residency rather than indefinitely expanding startup preload.

Attack playback holds windup for 320 ms, then displays impact and 480 ms recovery. Hurt and death are separate directional clips. Existing health, damage, XP, shadows, target markers, collision, cancellation and save/streaming paths apply.

## Acceptance boundary

Source artwork was visually inspected, including full-body gait phases and the clipped original fallen pose. This does NOT validate GPU frame coordinates, rendered proportions, attack weapon/foot registration, traversal, save/resume or performance. No tests, builds, type checks, browser automation or game launch ran. Manual in-game acceptance remains required before calling rendered art approved.
